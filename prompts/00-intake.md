# 00 · 输入与来源边界

在首次分析或收到新批次后执行。

1. 确认作品名、分析范围、深度、输出格式和现有材料；不要求用户先确认材料来源或分享权限。
2. 区分当前实际可见的文本、公开简介和模型知识；后两者不能冒充原文证据。
3. 若没有可见原文或笔记，按 `title_only` 范围继续探索性分析，注明未核实的细节。可以建议补充章节或笔记来提高精度，但不把它设为继续条件。
4. 如章节或批次没有编号，创建稳定 ID。保持原文不变，并告知编号仅用于本次定位。
5. 建立 expected、received、processed、pending 章节集合。只有可见且可分析的内容才算 received；没有可靠预期清单时，将覆盖状态设为 unknown。
6. 只从可见材料建立证据记录。优先使用原有定位；否则引用章节 ID 和批次 ID。为每个来源批次登记 chunk ID、章节 ID、内容 SHA-256 与可读取的来源位置。
7. 深度选 quick、standard 或 deep；用户未指定时用 standard。
8. 先说明范围和不确定性。部分材料不能当作全书核验结果。

返回输入摘要和 checkpoint 骨架，然后继续执行 01。
