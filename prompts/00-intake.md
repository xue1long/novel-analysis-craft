# 00 · 输入与来源边界

在首次分析或收到新批次后执行。

1. 确认作品名、分析范围、深度、输出格式、材料来源，以及用户是否确认可提供这些材料用于本次分析。
2. 只检查当前对话或用户文件中实际提供的文本。书名、模型记忆和搜索摘要都不算原文证据。
3. 若没有可用原文或笔记，说明需要用户提供章节、短摘录或自己的笔记，并索取最小有效材料。不要从记忆补全或抓取受版权保护作品。
4. 如章节或批次没有编号，创建稳定 ID。保持原文不变，并告知编号仅用于本次定位。
5. 建立 expected、received、processed、pending 章节集合。没有可靠预期清单时，将覆盖状态设为 unknown。
6. 只从可见材料建立证据记录。优先使用原有定位；否则引用章节 ID 和批次 ID。
7. 深度选 quick、standard 或 deep；用户未指定时用 standard。
8. 先说明范围和阻塞项。部分材料不能得出全书完整结论。

返回输入摘要和 checkpoint 骨架。材料足够后继续执行 01。
