# 03 · 灵魂：主题与情感

提炼 1–2 个核心主题，写成命题或张力，不只写题材标签。每个主题都连接到：

- 一个情节或选择；
- 这个选择的代价；
- 它如何改变角色行动或读者判断；
- 对应 evidence ID。

描述主导情感变化（例如“不信任 → 共同承担”）和主要转折。指出触发变化的事件、角色新获得的信息或作出的选择，以及情感变化如何改变后续行动。

总结 1–2 个有证据的优点和不足。如果范围不足以判断结局或问题，写成待验证问题，不强行定论。

使用 references/analysis-methods.md 与 references/quality-gates.md。必要时记录竞争性解释和置信度，并以稳定 ID 保存结果。
