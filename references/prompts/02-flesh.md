# 02 · 血肉：支线与角色

优先使用证据表和已提供材料；只有书名时可给探索性解读，并标明低置信度。

## 支线

逐条记录重要支线的名称、章节、角色、目标/冲突、转折、与主线的关系、汇合点和删除测试。具体说明删掉后会失去哪项因果、情感、主题或信息功能。若材料无法核实支线，将相关判断标为待核实。

## 角色

在现有信息允许时，分析主角、主要阻力来源和 2–3 个关键配角。每个角色记录作用、欲望、恐惧/弱点或信念、压力下的行为模式、关键选择及代价、起点至终点的变化（或未变化证据）、与主冲突的关系。将观察与解释分开。

有可见来源的判断标 evidence ID；其他判断标低置信度且不伪造引用。性格形容词本身不是证据。阻力可以来自社会、制度、环境或角色内在矛盾，不要默认存在传统反派。

按 `skill://novel-analysis-craft/references/quality-gates.md` 检查门槛。把 ID 和未解决问题保存至 checkpoint。
