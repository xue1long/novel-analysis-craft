# 05 · SOP 与练习

选择一张技巧卡，将其转换成可复用的写作 SOP：

- 写作目标与适用条件；
- 3–7 个具体步骤；
- 判断机制是否生效的检查项；
- 常见失败信号；
- 供原创化替换的变量。

生成一项目标为 500–1500 字的练习任务。练习只训练机制，不复用来源中的情节、人物、意象或可识别措辞。附一份标准清楚的评价量表，例如每项 0–2 分。

默认交付题目与量表，不替用户写练习片段。若用户提交草稿，按量表给出具体反馈，举例只引用用户自己的草稿，尊重其写作意图，并给出下一轮修改动作。只有实际评估后才标记为 evaluated。

在 checkpoint 保存所选卡片 ID、SOP、练习题、目标字数、量表和草稿状态。
