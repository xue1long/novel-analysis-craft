# 阶段质量门槛

每个阶段使用 not_started / partial / complete / blocked 状态，以及 not_checked / pass / revise / blocked 门槛。只有满足门槛才标 pass。只有书名时也可完成探索性分析，范围标为 `title_only`、章节覆盖标为 unknown，并把未经核实的判断标为低置信度。

`title_only` 时，下表的证据条件改为清楚标注信息来源和不确定性；通过门槛表示探索性任务完成，不表示已核对原文。

| 阶段 | 最低交付 | Pass 条件 | 需退回或标 partial 的情形 |
|---|---|---|---|
| Intake | 作品、范围、深度、现有材料与章节/批次清单 | 现有材料和未知项清楚，范围状态可报告 | 把只有书名的任务误报为原文核验 |
| 骨架 | 梗概或范围摘要、单句故事、目标/阻力、关键事件因果链、结构点 | 有材料时核对关键事件；没有材料时明确低置信度与覆盖限制 | 把未核实结局、情节或章节定位当作已核对事实 |
| 血肉 | 主线相关支线、主角、主要阻力、关键配角 | 支线功能与删除测试具体；角色判断关联行为证据 | 性格标签没有行为支撑；将非人阻力误写成传统反派；配角作用空泛 |
| 灵魂 | 主题、情感移动与转折、优缺点 | 主题连接情节选择和代价；情绪变化有触发事件 | 只有抽象主题词；情感转折没有事件；评价无来源支撑 |
| 技巧 | 深度对应数量的卡片 | 每卡写出动作、效果、机制、反事实、适用条件、迁移和风险；有来源时引用证据 | 只给技巧名称；复述原文替代分析；直接模仿风格 |
| 练习 | SOP、原创任务、量表 | 任务练目标技巧且给出 500–1500 字目标；评价量表可执行 | 任务要求复刻源小说/作者风格；没有评价标准；未提交草稿却声称完成 |
| 收尾 | 覆盖报告、阶段状态、限制、下一步、结构化输出 | 覆盖集合一致，证据引用可解析，待办明确，JSON 结构可读 | 缺章却宣称全书完成；引用悬空；checkpoint 无法续跑 |

## 深度模式的门槛

- quick：五阶段都有产物；技巧卡至少 1 张；练习题和评价标准齐备。
- standard：在有足够证据时覆盖全部显著支线/角色；技巧卡 3 张；含可复用 SOP。
- deep：对已声明范围逐章留痕；技巧卡 3–5 张；记录竞争性解释、反事实与来源限制。

当证据数量不足时，保留有用的探索性分析并标明不确定性；已有证据的引用仍须真实可追溯。
