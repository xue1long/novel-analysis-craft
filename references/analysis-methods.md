# 小说拆解分析方法

## 骨架：故事的因果脊柱

优先回答“谁想要什么、为什么现在必须行动、什么阻力改变了行动、结果又引出什么”。将关键事件写成有因果的动作链，而不是主题相似的事件清单：

**触发 → 选择 → 行动 → 代价/结果 → 新局面**

至少检查：

- 背景与核心设定是否改变角色可选行动；
- 主角身份、外在目标、内在需要或信念；
- 对手、环境、制度、时间限制等主要阻力；
- 开篇如何提出问题，铺垫如何积累代价，高潮如何迫使选择，结尾如何回应核心冲突；
- 若把开篇直接换成高潮，读者会失去什么因果、信息或情感积累。

若材料不含结局，明确只分析已提供区间，不推测闭环。

## 血肉：支线与角色

### 支线

记录支线名称、涉及章节/角色、目标与转折、对主线的功能、与主线汇合点、删除后的变化。删除测试不是机械删减：说明删掉后哪项因果、选择、情感、主题或信息功能会消失；若没有具体损失，标记为“可能可压缩”，而不是断言冗余。

### 角色

用行为证据支持性格判断。分别记录：

- 欲望、恐惧/弱点、信念或误判；
- 面对压力的稳定反应模式；
- 关键选择及其代价；
- 起点到终点的变化，或有证据说明“拒绝变化/未解决”；
- 与主角的核心冲突和对照关系。

反派只是阻力来源之一。无传统反派时，分析制度、灾难、误解、内在矛盾等。配角优先选 2–3 个对主线有显著推动、支持、补位、对照或冲突作用者。

## 灵魂：主题与情感

主题不是单一标签。优先写成作品反复检验的命题或张力，例如“忠诚在什么条件下变成共谋”。每项主题至少连接到：

- 一个具体情节或选择；
- 该选择付出的代价；
- 主题如何改变角色行动或读者判断。

情感分析用“从何种情绪/关系状态 → 变为何种状态”，标记触发转折、读者获得新信息的时点，以及它如何推动行动。不要用抽象情绪词代替具体转折事件。

优缺点都要具体并附证据。批评可讨论因果断裂、角色选择不可信、节奏重复、信息过早/过晚等；若来源范围不足以判断，列为待验证。

## 技巧拆解：从现象到可迁移机制

每张技巧卡回答：

1. **观察**：作者在什么位置做了什么可见的叙事动作？
2. **效果**：读者知道/误解/期待什么，情绪如何变化？
3. **机制**：信息、选择、时间、意象、视角或场景动作如何产生该效果？
4. **反事实**：若删掉、提前、延后或改写该动作，哪种效果会减弱？
5. **条件**：该技巧适合何种目标、题材、视角、读者知识状态？
6. **迁移**：如何用完全不同的角色、场景、道具和措辞实现类似机制？
7. **风险**：过度使用会变成什么问题？

不要停留在“悬念写得好”“人物鲜明”。把它写成可执行规则，例如“先让读者看到一个可重复辨认的异常，再给出两个相容解释；最终揭示必须回扣前置细节，并改变角色关系，而不只是补充答案”。

## 写作 SOP 与练习

将技巧卡转换为一组可复用动作：

- 适用目标与进入条件；
- 准备的角色欲望、阻碍、信息差；
- 3–7 个可执行步骤；
- 检查信号与常见失败；
- 可替换的场景变量，帮助形成原创版本。

练习任务默认 500–1500 中文字。练习评价使用明确量表，先说明目标，再给证据化反馈。没有用户草稿时只生成题目和量表，不能虚构练习成果。
